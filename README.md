# Goods Exhibition - 好物页面插件

一个用于快速搭建「好物推荐展示页」的 WordPress 插件，通过短代码即可在任意页面展示整洁的商品列表，适合个人博客、电商导购、团队推荐页等场景。

---

## 功能特性

### 前端展示
- Apple 风格卡片式商品展示，支持横向滚动浏览
- 海报幻灯片轮播（自动播放 + 圆点指示器 + 箭头导航）
- 按分类分组展示，支持自定义排序
- NEW 标签标记新品
- 点击卡片跳转外链，底部「了解更多」提示
- 响应式设计（桌面 3 列 / 平板 2 列 / 手机 1.5 列）
- 移动端滑动暗示动画（Peek Animation）
- 夜间模式 / Dark Mode 完整适配
- 图片懒加载 + 首屏海报优先加载（fetchpriority）
- 无 jQuery 依赖，纯 Vanilla JS

### 后台管理
- Tab 式管理面板（产品列表 / 添加新产品 / 分类管理）
- 产品搜索 + 按类别筛选
- 批量删除 / 批量移动至分类
- 拖动排序（筛选分类后可用，前端同步显示）
- 分类管理：添加、编辑、删除、排序
- 媒体库图片选择 + 直接上传
- 表单必填项验证（前端 + 后端双重校验）
- 海报图片自动裁切铺满（3:1 固定比例容器）

### 安全与性能
- Nonce 验证 + 权限检查
- 输入消毒 + MIME 类型验证
- Prepared Statements 防 SQL 注入
- 安全文件删除（路径遍历防护）
- Transient 缓存（12 小时自动刷新）
- 卸载时完整清理（uninstall.php）

## 安装

### 方法一：后台上传（推荐）

1. 下载插件 ZIP 文件
2. 登录 WordPress 后台
3. 前往 **插件 - 安装插件 - 上传插件**
4. 上传 ZIP 文件并安装
5. 点击 **启用插件**

### 方法二：手动上传

将 `goods_exhibition` 文件夹上传到 `wp-content/plugins/`，然后在后台启用。

---

## 使用方法

1. 在后台「好物页面 - 分类管理」中创建分类
2. 在「添加新产品」中填写产品信息
3. 新建 WordPress 页面，插入短代码：

```
[goods_exhibition]
```

4. 可选参数限制显示数量：

```
[goods_exhibition limit="10"]
```

## 后台管理

### 产品列表
- 搜索：按名称或描述模糊搜索
- 筛选：按类别下拉筛选
- 批量操作：批量删除、批量移动分类
- 拖动排序：筛选指定分类后，拖动行调整顺序

### 添加新产品
- 必填项：产品名称、描述、类别、图片
- 可选项：价格、跳转链接、NEW 标记、海报标记

### 分类管理
- 添加新分类（名称 + 排序权重）
- 编辑分类名称（自动同步产品数据）
- 删除空分类（有产品时禁止删除）

## 推荐图片尺寸

| 类型 | 推荐尺寸 | 说明 |
|------|----------|------|
| 产品图片 | 720x720px | 1:1 正方形，自动裁切铺满 |
| 海报图片 | 1920x640px | 3:1 比例，自动裁切铺满 |
